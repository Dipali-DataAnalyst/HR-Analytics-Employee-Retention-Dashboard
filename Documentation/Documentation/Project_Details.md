# HR Analytics Dashboard – Project Details

## Project Overview

The HR Analytics Dashboard is an Excel-based data analytics project designed to analyze employee information and present important HR metrics through an interactive dashboard.

The project uses employee-level data and transforms it into KPI analysis and visualizations that can be used to understand workforce trends.

## Problem Statement

HR teams often work with large amounts of employee data. Raw data alone does not easily communicate workforce trends.

This project addresses the problem by creating structured analysis and visual dashboards that make HR information easier to understand.

## Objectives

* Analyze employee attrition.
* Understand department-wise workforce distribution.
* Analyze employee satisfaction.
* Examine compensation patterns.
* Analyze employee experience.
* Understand work-life balance.
* Analyze workforce demographics.
* Create meaningful HR KPIs.
* Present insights through an interactive dashboard.

## Data Analysis

The workbook includes a main employee dataset and multiple KPI analysis sheets.

The analysis covers:

* Attrition
* Department
* Gender
* Job Role
* Monthly Income
* Hourly Rate
* Total Working Years
* Years at Company
* Work-Life Balance
* Job Satisfaction
* Marital Status
* Education Field
* Years Since Last Promotion

## Dashboard Development

The dashboard was developed using Microsoft Excel.

The workflow included:

1. Reviewing the employee dataset.
2. Preparing the data for analysis.
3. Creating Pivot Tables.
4. Developing KPI calculations.
5. Creating charts and visualizations.
6. Organizing the visualizations into a dashboard.
7. Applying filters/interactivity.
8. Reviewing the dashboard for usability and presentation.

## Business Value

The dashboard provides a high-level view of workforce trends and can help HR stakeholders explore potential areas related to:

* Employee retention
* Employee satisfaction
* Workforce distribution
* Compensation
* Career progression
* Work-life balance

## Limitations

The analysis identifies relationships and patterns in the available data. It does not establish causal relationships.

For example, a department with higher attrition does not automatically mean that the department itself causes employee turnover. Additional HR information would be required for deeper investigation.

## Tools

* Pivot Charts

## Outcome

The final outcome is an interactive HR Analytics Dashboard that converts employee data into understandable KPIs and visual insights.
